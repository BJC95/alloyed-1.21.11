
FluxedMod; Alloyed
===
Fluxed; Alloyed is a Vanilla+ mod that adds more tool tiers to Minecraft!
Currently, this mod has Rose Gold, (1 Copper + 3 Gold) that mines as fast as gold,
with the durability of Copper, and Fluxed Metal (2 Copper + 4 Redstone) that acts as a
Diamond equivalent that has faster mining speed, but way less durability. (I will make it more interesting later.)
